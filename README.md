# BlackTree AI

A premium AI chat assistant app powered by Claude Opus 4 - the most advanced AI model available.

## Features

### AI Chat
- Chat with BlackTree AI - smarter than ChatGPT and Grok
- Expert-level knowledge across all fields
- Location and weather awareness
- Context memory throughout conversations

### Settings
- User profile display
- Clear chat history
- Contact support
- Rate the app
- Privacy policy
- Terms of service
- Version info
- Sign out

## Tech Stack

### Mobile App
- Expo SDK 53 with React Native
- Expo Router for navigation
- NativeWind (TailwindCSS) for styling
- React Native Reanimated for animations
- RevenueCat for subscriptions

### Backend
- Bun runtime
- Hono web framework
- Claude Opus 4 (Anthropic API)
- Prisma with SQLite
- Better Auth for authentication

## API Endpoints

- `POST /api/ai/chat` - Chat with BlackTree AI

## Design

Dark premium theme with cyan accents. Clean, minimal interface focused on conversation.
